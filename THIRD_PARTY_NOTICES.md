# Dependências e referências de terceiros

Este repositório contém código original para treinamento numérico e visualização. As bibliotecas abaixo são instaladas separadamente e permanecem sujeitas às respectivas licenças.

| Projeto | Uso | Licença | Fonte |
| --- | --- | --- | --- |
| Manim Community | Construção e renderização das cenas | MIT | <https://github.com/ManimCommunity/manim> |
| NumPy | Álgebra linear, geração dos dados e treinamento | BSD-3-Clause | <https://github.com/numpy/numpy> |
| PyAV | Leitura, validação e recodificação do vídeo | BSD-3-Clause | <https://github.com/PyAV-Org/PyAV> |
| Pillow | Exportação e inspeção de quadros | MIT-CMU | <https://github.com/python-pillow/Pillow> |
| ManimML | Referência de estudo para padrões de visualização de redes neurais; nenhum código do projeto é incorporado | MIT | <https://github.com/helblazer811/ManimML> |

O conjunto de dados utilizado na animação é sintético e gerado localmente pelo módulo `neural_training_numpy.py`.
